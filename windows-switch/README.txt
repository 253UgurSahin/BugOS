BugOS Switch
============

This little program helps you switch from Windows to BugOS.

1. Unzip the zip file (right-click -> Extract All).
2. Double-click "Start BugOS Switch.bat".
3. Follow the four steps on the screen:
   1. Check         - can your computer run BugOS?
   2. Make USB stick - put BugOS on a USB stick (at least 8 GB).
   3. Take your files - a copy of your photos, documents and more, on that
                       stick or another USB drive.
   4. Keep Windows?  - only if you want Windows and BugOS side by side.

For "Put BugOS on the stick" and "Keep Windows", Windows asks for
permission (administrator). That is normal.

The USB stick stays usable in Windows: it is called BUGOS, and you can
put your own files on it (leave the LiveOS folder alone). Done with it?
"Empty the stick" makes it a normal, empty stick again.

Questions or problems? https://github.com/253UgurSahin/BugOS/issues

----- Nederlands -----

BugOS Switch
============

Dit programmaatje helpt je om van Windows over te stappen naar BugOS.

1. Pak de zip uit (rechtermuisknop -> Alles uitpakken).
2. Dubbelklik op "Start BugOS Switch.bat".
3. Volg de vier stappen op het scherm:
   1. Controleren        - kan je computer BugOS aan?
   2. USB-stick maken    - BugOS op een USB-stick (minstens 8 GB).
   3. Bestanden meenemen - een kopie van je foto's, documenten en meer, op
                           die stick of een andere USB-schijf.
   4. Windows houden?    - alleen als je Windows en BugOS naast elkaar wilt.

Voor "BugOS op de stick zetten" en "Windows houden" vraagt Windows om
toestemming (beheerder). Dat is normaal.

De USB-stick blijft bruikbaar in Windows: hij heet BUGOS, en je kunt er
gewoon je eigen bestanden op zetten (laat de map LiveOS staan). Klaar?
"Stick leeg maken" maakt er weer een gewone, lege stick van.

Vragen of problemen? https://github.com/253UgurSahin/BugOS/issues
